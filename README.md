Large-scale infrastructure projects across India routinely suffer from critical time and cost overruns due to delayed, fragmented, and unlinked site progress reporting. While project plans are mapped down to granular L5/L6 activity levels in systems like Primavera P6 and MS Project, ground-level progress is reported in non-standard daily reports, discipline Excel sheets, and handwritten diaries. Planners are forced to manually reconcile these sources, causing status tracking to lag by days or weeks, rendering delay analysis outdated, and losing valuable historical productivity metrics.   To resolve this execution-to-planning gap, our solution presents an AI Time Agent—a chat and voice-enabled bridge for site supervisors that automatically ingests and maps real-time field progress directly to schedule activity IDs. Site supervisors submit progress effortlessly using natural language voice notes or text (in Hindi, English, or Hinglish) via WhatsApp or Telegram without filling out rigid forms. Additionally, the system ingests unstructured text DPRs, discipline Excel files, and photos of site diaries via OCR.   Using OpenAI Whisper for speech recognition, LLM-driven structured JSON extraction, and a dual-matching engine combining RapidFuzz fuzzy matching with Sentence-BERT semantic search, the platform maps field terminology to project schedule tasks. High-confidence matches (≥85%) automatically update actual start/finish dates in Primavera P6 / MS Project via MPXJ with a complete audit trail. Borderline entries (60–84%) route to a planner review queue, while unmapped tasks (<60%) flag potential scope changes. This system delivers same-day schedule visibility, reduces planner reconciliation overhead, and builds a queryable historical dataset for accurate future project estimates.# AI-Time-Agent
